Northstar Retail Co. — Support Deflection MVP
 Project Overview
The Northstar Retail Co. Support Deflection MVP is a digital self-service solution designed to reduce repetitive customer-support requests by helping customers find answers to common questions without needing to contact a support agent.
The MVP focuses on common retail support needs such as:
Checking order status
Understanding returns and refunds
Checking product availability
Navigating customers to the right information
Providing clear self-service support flows
Problem Statement
Northstar Retail Co. receives repetitive customer-support questions that could be answered through simple self-service experiences.
This creates unnecessary workload for support teams and can increase customer waiting times.
Our MVP aims to address this problem by creating an easy-to-use support experience that allows customers to quickly find answers to common questions.
MVP Objectives
The project aims to:
Reduce repetitive support requests.
Help customers find information independently.
Improve navigation to common support resources.
Provide simple and clear self-service flows.
Demonstrate how support deflection can improve the customer experience.
Key Features
Order Status
Customers can access information about their order and understand its current status.
Returns & Refunds
Customers can find guidance on return and refund processes.
Product Availability
Customers can check whether products are available.
Support Navigation
Customers are guided toward the appropriate information or support option based on their needs.
Sample Data & Testing
The MVP uses sample data to demonstrate and test the core support flows.
